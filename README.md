# Power Query + Tableau 실전 분석 — 전자책 홈

이 전자책은 영상 강의 없이도 단독 학습이 가능한 **독립형 지식 문서**다.
Power Query로 데이터를 정제하고, Tableau로 목적에 맞는 차트를 만들고, 최종적으로 대시보드를 완성하는 전체 흐름을 담았다.

---

## 이 강의로 할 수 있는 것

수강 완료 후 다음을 실행할 수 있다.

- 엑셀 원본 데이터를 Power Query로 자동 정제 파이프라인으로 만든다.
- 분석 질문을 먼저 정의한 뒤, 그 질문에 맞는 차트를 선택하고 제작한다.
- 기본 계산식과 테이블 계산으로 KPI와 비율 지표를 만든다.
- 정보 위계가 설계된 대시보드를 완성하고 배포한다.

**이 강의로 할 수 없는 것**: LOD 심화, 맵 차트, 산점도, Union 고급 기법 — 이 항목들은 부록에서 별도 제공한다.

## 전자책 활용 방법

- 각 장은 **영상 없이도 재현 가능**하도록 단계별 실습(`따라하기`)을 제공한다.
- 장 말미의 **실무 체크리스트**로 핵심 행동을 점검한다.
- **토글(`🔽`)** 항목은 심화 내용 또는 정답 확인 전용이다. 본문 학습에는 필수가 아니다.
- **부록(Level 3)**에는 본 강의 범위를 초과하는 심화 내용(LOD, 맵 차트 등)을 별도 제공한다.
